# Grecian Computer Puzzle Solver (MATLAB)

Solves the Grecian Computer, a puzzle of five stacked rotating wheels whose visible numbers must sum to
42 in every one of the 12 columns. The solver steps through every combination of wheel rotations,
accounting for which numbers each wheel's cut-outs hide or reveal, and prints how many times to turn
each wheel from the starting position.

## Running it

Open this folder in MATLAB and run `GrecianComputerSolver.m`.
